This repo holds a single original line for make.fun's "Funniest Forecast for a City That Isn't": a deadpan weather forecast for Nowhereville, a city nobody checks on. The line runs 88 characters and fits the competition's 1–120 character, one-line gate. It reads like a real forecast — 100% rain against 0% attention — and ends on the forecaster telling you to bring an umbrella anyway. `main.py` checks the line first — length, blankness, single-line shape — then writes it to `/output/entry.txt` and prints it.

## Run it

```sh
python3 main.py
```
